# Mais Doces

Sistema desktop para gerenciar uma confeitaria de doces gourmet, feito no Projeto Integrador do curso.

## Status do projeto

Em desenvolvimento

## Objetivo do software

O objetivo do Mais Doces é ajudar uma confeitaria a organizar o dia a dia, substituindo cadernos e planilhas. Com o sistema dá para registrar as vendas e as encomendas, acompanhar a produção dos pedidos, controlar o estoque dos produtos e saber quanto entrou e saiu do caixa.

Cada funcionário acessa só as telas do seu cargo (gerente, atendente, confeiteiro ou financeiro).

## Funcionalidades

- RF01 - Login de funcionários com usuário e senha
- RF02 - Cadastro de funcionários e seus cargos (gerente)
- RF03 - Cadastro de clientes
- RF04 - Cadastro de fornecedores
- RF05 - Cadastro de produtos com preço, quantidade e validade
- RF06 - Venda de balcão com cálculo do total e baixa no estoque
- RF07 - Encomendas com data de entrega e ocasião (aniversário, casamento etc.)
- RF08 - Controle da produção das encomendas (custo e status)
- RF09 - Caixa com entradas, saídas e vendas a receber
- RF10 - Menu com resumo do dia (vendas, saldo e encomendas pendentes)

## Tecnologias

- Java
- Java Swing (telas)
- NetBeans
- MySQL e MySQL Workbench
- JDBC
- Figma (protótipo das telas)
- Git e GitHub

## Como executar

1. Deixe o MySQL ligado.
2. Abra o projeto no NetBeans e execute (F6).
3. Na primeira vez o sistema cria o banco de dados sozinho. Se o MySQL tiver senha, o sistema pede para digitar.

Usuários para teste (todos com senha `123`): `admin`, `atendente`, `confeiteiro` e `financeiro`.
